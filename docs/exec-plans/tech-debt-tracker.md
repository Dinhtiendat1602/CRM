# SỔ GHI NỢ KỸ THUẬT - ZEN CRM

> Theo dõi các bug tạm hoãn, đoạn code cần refactor, và vấn đề hiệu năng cần tối ưu.  
> Mỗi mục phải có: mô tả, mức ưu tiên, feature liên quan, và kế hoạch xử lý.

---

## Quy ước mức ưu tiên

| Mức | Ý nghĩa | Hạn xử lý |
|:---|:---|:---|
| 🔴 `P0-Critical` | Gây crash hoặc mất dữ liệu | Phải fix ngay trong sprint hiện tại |
| 🟠 `P1-High` | Ảnh hưởng chức năng chính | Fix trước khi kết thúc sprint |
| 🟡 `P2-Medium` | Nợ kỹ thuật, code smell | Fix trong sprint kế tiếp |
| 🟢 `P3-Low` | Nice-to-have, tối ưu hiệu năng | Khi có thời gian rảnh |
